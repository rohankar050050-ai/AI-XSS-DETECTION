# AI-Based Cross-Site Scripting (XSS) Detection System

## Overview

This project is an AI-powered Cross-Site Scripting (XSS) Detection System developed using Node.js, JavaScript, Express.js, SQLite, and Machine Learning. The application analyzes user inputs and HTTP requests to identify potential XSS attacks and classify them as malicious or safe.

The system combines machine learning with traditional detection techniques to improve the accuracy of identifying XSS vulnerabilities.

---

## Features

- AI-based detection of Cross-Site Scripting (XSS) attacks
- Machine Learning model for malicious input classification
- Real-time scanning of user input
- Web interface for testing and analysis
- SQLite database for storing scan results
- Attack metrics and performance evaluation
- Detection of common XSS payloads

## Installation

Clone the repository

```bash
git clone https://github.com/rohankar05050-ai/AI-XSS-DETECTION.git
```

Go to the project folder

```bash
cd AI-XSS-DETECTION
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm start
```

or

```bash
node server.js
```

Open your browser and visit

```
http://localhost:3000
```
